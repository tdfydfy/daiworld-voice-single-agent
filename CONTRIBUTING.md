# Contributing

1. Keep Web and HarmonyOS clients aligned with the documented protocol.
2. Do not add provider credentials, local paths, production domains, or private conversation data.
3. Add or update tests for protocol, authentication, audio, artifact, and reconnect behavior.
4. Run the commands in `docs/NATIVE_TEST_MATRIX.md` before opening a pull request.
5. Describe security and privacy impact in the pull request when changing data flow or deployment behavior.
