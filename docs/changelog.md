# 变更记录

这里只记录影响产品基线的里程碑，不罗列每次构建哈希、设备编号或临时排障过程。

## 2026-08-17 - 附件链路稳定

- 支持 `MEDIA:`、`sandbox:`、`file:`、裸绝对路径和 Markdown 包装的本地附件引用。
- 支持按常见图片、文档、表格、演示文稿、文本和压缩包后缀识别附件。
- HTTPS 文件链接转换为附件令牌，客户端不再显示域名代替文件。
- 本地服务器路径不再出现在消息正文；图片内联，Word 等文件显示为附件。
- 增加 `VOICE_ARTIFACT_ALLOW_ALL_READABLE`，同权限部署以 Hermes/Adapter 的 OS 可读权限为边界。
- HarmonyOS 真机完成图片和非图片文件验收，稳定基线落在 Adapter `09f0ed4`。

## 2026-08-12 - HarmonyOS 1.2.16

- 统一语音运行时、消息流和 Agent 体验。
- 收敛 `关闭话筒`、`打开话筒`、`停止任务`、`退出软件` 的控制语义。
- 完成网关心跳、Session 恢复、离线/远端语音选择和前后台资源管理。
- 审批、澄清、历史、模型切换和语音提示进入统一对话体验。

## 2026-08-10 至 2026-08-11 - Single Agent 原生化

- HarmonyOS 客户端从迁移方案进入可安装、可连接和可持续语音的原生实现。
- Adapter 接入 Hermes 动态 Profile 目录、JSON-RPC、ASR/TTS 和历史详情。
- Web Native 定位为协议预览，HarmonyOS 成为主要移动端交付面。

更细粒度的实现记录请使用 `git log` 和对应提交查看。
