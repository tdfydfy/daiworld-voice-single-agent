# 关键决策

本文只保留当前长期有效的决策。实现过程、已完成计划和逐次修复由 Git 历史记录。

## D001 Hermes 是唯一 Agent 权威

客户端和 Adapter 不复制 Session、上下文、工具调度、审批权限、模型状态或历史数据库。所有 Agent 行为以 Hermes 协议和服务端事件为准。

## D002 HarmonyOS 是主要移动产品

Web Native 保留为协议预览、调试和回归入口；新移动体验以 HarmonyOS 真机为验收对象。

## D003 Profile 目录动态发现

Adapter 从 Hermes `/api/status.profiles` 生成公开 Agent 目录，首次读取后缓存，只在用户显式刷新或进程重启后重读。客户端不硬编码 Profile 数量、名称或地址。

## D004 正式部署复用单一 Hermes Dashboard

Adapter 通过请求级 Profile 隔离复用 Hermes 官方 Dashboard/API，不为每个 Agent 常驻一套 Native 专用 Hermes runtime。旧固定 Profile URL 只作兼容和回滚。

## D005 语音链路与输入路由分离

冷启动由用户手动开启一次完整采集/ASR 链路。关闭话筒只切换到系统命令路由，不停止采集；打开话筒恢复普通对话。ASR、Agent 和 TTS 保持独立生命周期。

## D006 破坏性命令精确匹配

`停止任务`、`退出软件` 和审批 `同意`/`取消` 只按规范化后的精确整句触发，避免普通对话被误解释为破坏性操作或授权。

## D007 本地立即停止不冒充服务端完成

`停止任务`先清理客户端本地输出，再发送 Hermes `session.interrupt`。UI 可以确认本地停止和请求已发出，但不能据此宣称服务端全部排队工作已经收敛。

## D008 附件使用短期不透明令牌

客户端永远不接收服务器绝对路径。Adapter 验证本地文件或 HTTPS 引用后签发内存态短期令牌；图片内联，其他文件按附件打开。远程 HTTPS 由令牌端点重定向，不由 Adapter 代理下载。

## D009 同权限部署以 OS 可读性为附件边界

正式 Hermes/Adapter 同权限部署设置 `VOICE_ARTIFACT_ALLOW_ALL_READABLE=true`，允许投递该进程身份可读的普通文件，同时保留文件存在性、类型、可读性和大小校验。需要更小边界的部署可改用 `VOICE_ARTIFACT_ROOTS`。

## D010 非显式引用按后缀识别附件

为兼容模型返回的 `sandbox:`、`file:`、裸路径和 Markdown 链接，Adapter 对常见图片、文档和压缩格式按后缀识别。未知协议、HTTP、普通网页和未知后缀不放行，避免把所有文字路径或 URL 都变成附件。

## D011 客户端会话偏好不能覆盖服务端契约

移动端系统指令只影响新建 Session 的表达偏好。Adapter 必须合并 Agent 预设、客户端偏好和服务端强制契约，附件、安全和协议规则始终由服务端兜底。

## D012 测试证据分层

单元测试、静态检查、HAP 构建、安装拉起和真机功能验收是不同证据层。低层通过不得替代高层结论；语音听感和视觉体验必须由真实设备与用户判断。
