# 路线图

当前版本进入稳定维护阶段。路线图只记录尚未完成的方向，已交付内容见 [changelog.md](./changelog.md)。

## 近期

- 为关键真机流程建立可重复的发布记录模板，降低仅凭口头反馈回归的风险。
- 补充不同 HarmonyOS 设备、耳机和网络切换场景的兼容性证据。
- 完善附件打开失败、令牌过期和文件过大的用户提示。
- 观察 `VOICE_ARTIFACT_ALLOW_ALL_READABLE` 正式部署日志，确认失败诊断足够且不泄漏路径。

## 后续

- 评估 HarmonyOS 安全存储稳定后，将长期访问口令迁移到可靠的系统安全存储。
- 在不改变 Hermes Session 权威的前提下改善离线语音启动速度和长时间监听耗电。
- 评估 Web Native 从旧音频处理 API 迁移到 AudioWorklet 的兼容性收益。
- 为受支持文件类型、大小限制和客户端打开能力建立跨端一致性测试。

## 不进入本路线图

- 在客户端实现第二套 Agent 运行时或历史数据库；
- 主持人多 Agent 编排、Profile 间共享上下文；
- 用模糊自然语言触发审批或破坏性系统命令；
- 绕过 Hermes/Adapter 进程的 OS 文件读取权限。
