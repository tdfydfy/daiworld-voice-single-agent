- 核心目标：先建立核心功能的独立边界，再定位并修复息屏长文播报和消息重读问题。

- 关键约束：本次只记录问题和计划，不开发、不修改业务代码；拆解过程必须保持现有行为和协议契约。
- 初始范围：优先拆解 `SingleAgentController.ets`（约 3636 行），并核对 `Index.ets`（约 1822 行）和 `PcmAudio.ets`（约 1102 行）的边界耦合；不预先扩大到 Web 或 Hermes 服务端。
- 计划去向：[当前计划](../PLAN.md)；长期路径见[项目路线图](../roadmap.md)。
- 待确认：息屏问题具体发生在系统 TTS 分段、后台音频任务、音频焦点/路由、生命周期恢复或 PCM 播放器哪一层；按钮无效发生在点击绑定、文本过滤、统一输出入口还是播放状态回调。
