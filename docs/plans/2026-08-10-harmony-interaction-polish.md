# HarmonyOS 交互细节优化

## 已确认范围

- 设置页增加持久化的调试模式开关，默认关闭；ASR/TTS 调试状态仅在调试模式显示。
- 麦克风状态简化为“麦克风已开（手机/耳机）”。
- 输出设备按系统实际路由显示听筒、扬声器或耳机，并允许在当前可用设备中切换；默认优先耳机，无耳机时默认听筒。
- 消息时间居中，助手靠左、用户靠右，不显示发送方名称。
- 助手“过程”区域仅显示模型名、具体 Provider 名和总耗时，使用无标签的紧凑格式；不再重复显示思考时长。
- 自动恢复的 Session 不存在时静默创建新 Session；加载历史对话期间显示加载状态并禁用输入。
- 顶部左侧放 Agent 选择和连接状态，右侧放 Logo、历史和设置。
- Provider 协议保留现有类型字段，并补充具体服务名称；客户端在字段缺失时兼容旧数据。

## 实施顺序

1. [x] 设置、消息和顶部布局。
2. [x] Session 恢复与历史加载状态。
3. [x] 音频实际路由与选择。
4. [x] Provider 具体名称协议与兼容。
5. [x] 静态检查、ArkTS 类型检查和真机包构建。
